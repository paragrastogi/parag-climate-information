# Climate Information Data Model Specification

An open-source data model specification for climate information, developed through a stakeholder consensus process by the Building Data Exchange Committee of IBPSA-USA (the US affiliate of the International Building Performance Simulation Association).

**Read the specification at https://ibpsa-usa.github.io/climate-information/.** Its About page covers the model's scope, status, open questions, and working group.

## Building the documentation locally

```bash
uv sync      # install dependencies, including Lattice
uv run doit  # validate the examples and build the website
```
